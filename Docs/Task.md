# 実装タスク

設計書 [Plan.md](./Plan.md) に沿って、各項目をおおむね1つのコミットで完了できる粒度に分割する。上から順に進める。各コミットでは該当タスクの動作確認も行う。

## 1. アプリの土台

- [ ] **Vite・TypeScriptの初期構成を作る** — `package.json`、TypeScript設定、Vite設定、開発・ビルド用スクリプトを用意し、空のアプリを起動・ビルドできるようにする。
- [ ] **単一画面の基本レイアウトを作る** — 問題表示、地図領域、操作ボタン、絞り込み領域、結果表示領域を配置し、PCとスマートフォンで崩れない骨組みを作る。
- [ ] **ゲーム状態と自治体データの型を定義する** — 出題中・ピン配置済み・結果表示の状態、自治体属性、地方区分などを型として定義する。

## 2. 地図データ

- [ ] **N03データ取得・生成手順を整備する** — 国土数値情報の対象データと取得元を記録し、生成に必要なツールと再実行可能な手順を用意する。
- [ ] **自治体ポリゴンを出題単位に統合する** — 政令指定都市は市単位に統合し、東京23区は区単位を維持する。複数ポリゴン、飛び地、北方領土の対象6村を扱う。
- [ ] **地図データを簡略化してTopoJSON化する** — 境界の表示品質を保ちながら静的配信用TopoJSONを生成する。
- [ ] **自治体メタデータを生成する** — 自治体コード、表示名、種別、郡名、地方、内部用都道府県、重心緯度を生成する。
- [ ] **同名市の相対位置情報を生成する** — 市名が重複するグループを抽出し、重心緯度順の順位・件数を静的データに格納する。
- [ ] **生成データの検査を追加する** — ID重複、欠落属性、形状なし、出題単位の誤り、地方区分の不正などを検出する。

## 3. 地図表示と操作

- [ ] **Canvasに白地図を描画する** — D3-geoで自治体ポリゴンを描き、地名や地図タイルを表示しない。
- [ ] **都道府県境界と市町村境界を描き分ける** — 都道府県境界を太く、市町村境界を細く描画する。
- [ ] **ズーム・パンと境界の表示調整を実装する** — d3-zoomでマウス・タッチ操作に対応し、ズームに応じて市町村境界の線幅・透明度を調整する。
- [ ] **地方選択に応じた地図範囲調整を実装する** — 選択範囲が地図に収まるよう初期表示・選択変更時のズームを調整する。
- [ ] **地図タップでピンを配置・移動できるようにする** — タップとドラッグ・ピンチ操作を区別し、ピン位置を再調整できるようにする。
- [ ] **ピン位置を自治体ポリゴンに照合する** — ポリゴン内判定を実装し、複数形状のどれかに入れば正解、海上などは不正解と判定する。
- [ ] **正解位置・ポリゴンを地図に表示する** — 回答後に正解ポリゴンを強調し、プレイヤーのピンとの位置関係を見せる。

## 4. 出題とゲーム進行

- [ ] **地方フィルターを実装する** — 8地方の複数選択、全選択の初期状態、出題中の変更に対応する。
- [ ] **重複なしのランダム出題を実装する** — 選択地方に属する自治体をシャッフルして出題し、全問終了後に再シャッフルする。
- [ ] **問題文の表示ルールを実装する** — 区・市・町村の表示名を出し、都道府県名は画面に出さない。同名市には順位に応じた相対位置を表示する。
- [ ] **町村の郡名開示操作を実装する** — 町村問題に限りボタンを表示し、押した後だけ郡名を表示する。
- [ ] **回答を確定して結果を表示する** — ピン配置後に確定でき、正誤のみを表示する。誤答時は確定直後に正解を地図上へ表示する。
- [ ] **答えを見る操作を実装する** — 回答を確定せずに正解を表示し、結果表示状態へ遷移させる。
- [ ] **次の問題へ進む操作を実装する** — 結果表示後に次問を開始し、ピンと前問の結果表示をリセットする。
- [ ] **フィルター変更時に出題を切り替える** — 現在の地方選択に応じたプールから新しい問題を出し、結果・ピン状態を初期化する。

## 5. 画面仕上げと公開

- [ ] **PC向けレイアウトを仕上げる** — 地図を中央に大きく配置し、問題を上部、操作を下部、絞り込みを左側に配置する。
- [ ] **スマートフォン向け操作とレイアウトを仕上げる** — 縦画面で問題・地図・固定操作ボタンを配置し、絞り込みを開閉できるボトムシートにする。
- [ ] **利用規約とデータ出典を表示する** — 国土数値情報の利用規約に沿った出典表記をアプリ内に追加する。
- [ ] **GitHub Pages向けにビルド設定を整える** — 公開パスを設定し、静的ファイルだけで配信できる成果物を生成する。
- [ ] **公開手順を文書化する** — ビルド・GitHub Pages設定・データ更新手順をREADME等に記載する。
